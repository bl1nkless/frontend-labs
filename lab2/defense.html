Пункт 4.3.2

Усі способи позиціонування + приклади + пристрої + 3 зміни

[ДІЯ] Показуєш рядки 12–14 та 49–52 у lab2/index.html (і можна згадати рядок 11 у activities.html).
🗣️ Диктувати в ухо

Назву всі п’ять значень CSS-властивості position:

Перше — static: позиціонування за замовчуванням у звичайному потоці, властивості top, left на нього не діють. / Друге — relative: зміщує елемент відносно його нормального місця, не ламаючи потік, і слугує точкою відліку для дочірніх абсолютних блоків — / у мене це body на дванадцятому рядку та #founders на п’ятдесят першому. / Третє — absolute: вириває елемент із потоку й позиціонує відносно найближчого позиціонованого предка — / у мене це header на тринадцятому рядку. / Четверте — fixed: фіксує елемент відносно вікна браузера незалежно від прокручування — / у мене це header на одинадцятому рядку сторінки activities.html. / П’яте — sticky: поводить себе як відносний блок, доки при прокручуванні не досягне межі top: 0, після чого прилипає — / це панель nav на чотирнадцятому рядку index.html.

Щодо переваг і недоліків на різних пристроях: / fixed зручний на широких десктопах для швидкого доступу до шапки, але на смартфонах із малим екраном постійно забирає корисну висоту. / absolute вимагає жорстких відступів на кшталт padding-top: 8rem, тому на вузькому екрані багаторядкова шапка може налізти на контент. / sticky адаптивніший для меню, але може перекриватися елементами з більшим z-index або не спрацювати при overflow: hidden у батька.

Внесу три зміни у Flex-елемент .buttons. / Перша — змінюю order: 4 на order: 0, переміщуючи блок кнопок на початок форми. / Друга — змінюю align-self: flex-end на center. / Третя — замість flex-shrink: 0 додаю flex-basis: 100%, щоб кнопки зайняли окремий повний рядок. / Зберігаю і показую в браузері: кнопки перемістились угору форми.

🗣️ Диктувати в ухо — Питання 4.6: Пріоритети таблиці стилів

У CSS пріоритет визначається походженням стилів, специфічністю селектора та порядком підключення. / Від найвищого до найнижчого: / найвищий має директива !important, / далі йдуть вбудовані інлайнові стилі в атрибуті style, / потім селектори ідентифікаторів #id, / далі класи, атрибути та псевдокласи, / ще нижче — селектори тегів та псевдоелементи. / При однаковій специфічності перемагає правило, записане пізніше — тому внутрішня таблиця <style> у моєму коді перевизначає підключений раніше файл style.css.

Найнижчий пріоритет мають базові стилі браузера за замовчуванням, тобто User-Agent stylesheet, / а серед авторських стилів — універсальний селектор зірочка зі специфічністю нуль / та успадковані від батьківських тегів властивості.

🗣️ Диктувати в ухо — Питання 4.7: Веб-дружні шрифти

Веб-дружні, або web-safe шрифти — це шрифти, які за замовчуванням встановлені в більшості операційних систем, / таких як Windows, macOS та Linux, / тому коректно відображаються у браузері без завантаження із зовнішніх серверів. / Вони часто використовуються як резервні, якщо вебшрифт не завантажився. / Приклади з мого файлу style.css на сьомому і дванадцятому рядках: Georgia із родини serif та Arial із родини sans-serif; / також до них належать Times New Roman, Verdana і Courier New.

На цьому захист лабораторної роботи номер два завершено. / Дякую за увагу!
