Що таке DOM і коли браузер її створює? DOM (Document Object Model) — це об’єктна модель документа, яка представляє HTML-сторінку у вигляді ієрархічного дерева вузлів-об’єктів, завдяки чому JavaScript може динамічно читати й змінювати вміст, структуру та стилі елементів. Браузер створює DOM автоматично під час завантаження та покрокового парсингу HTML-коду зверху вниз і після побудови дерева генерує подію DOMContentLoaded.

Що таке BOM і наведіть приклади методів для управління вікнами браузера. BOM (Browser Object Model) — це набір об’єктів браузера на чолі з глобальним об’єктом window для роботи з вікном браузера та середовищем, куди входять location, history, navigator та screen. Методи window для управління вікнами: window.open() та window.close() для відкриття й закриття вікна, window.moveTo() та window.resizeTo() для зміни положення й розміру, window.scrollTo() та window.scrollBy() для прокрутки, а також діалогові вікна alert(), confirm() та prompt().
