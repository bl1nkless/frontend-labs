4.3–4.4. Контрольні питання (DOM та BOM)
Пункти 4.3 та 4.4

Що таке DOM і коли створюється; що таке BOM і методи

[ДІЯ] Дивишся в камеру, відповідаєш упевнено.
🗣️ Диктувати в ухо — Питання 4.3: DOM

DOM, або Document Object Model — це об’єктна модель документа, / яка представляє HTML-сторінку у вигляді дерева вузлів — елементів, атрибутів і тексту, / щоб JavaScript міг читати та змінювати структуру, вміст і стилі сторінки.

Браузер створює DOM автоматично під час завантаження та покрокового парсингу HTML-документа, / і повністю завершує його побудову до настання події DOMContentLoaded — / саме тому скрипт підключено з атрибутом defer, щоб він виконувався вже після побудови DOM.

🗣️ Диктувати в ухо — Питання 4.4: BOM

BOM, або Browser Object Model — це об’єктна модель браузера, / яка надає JavaScript доступ до самого вікна браузера та середовища поза межами HTML-документа. / Кореневим об’єктом є window, а до BOM також належать об’єкти location — як у мене location.search на вісімнадцятому рядку — history, navigator і screen.

Приклади методів для керування вікнами браузера: / window.open() відкриває нове вікно або вкладку, / window.close() закриває поточне вікно, / window.resizeTo() і window.moveTo() змінюють розмір і позицію вікна, / window.scrollTo() прокручує вікно до заданих координат, / а також діалогові методи alert(), як на сімдесят четвертому рядку, confirm() та prompt().

На цьому захист лабораторної роботи номер чотири завершено. / Дякую за увагу!
