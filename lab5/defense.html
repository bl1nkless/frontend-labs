4.3–4.6. Контрольні питання

Теоретичні відповіді

🗣️ Диктувати в ухо — Питання 4.3: Прийоми адаптивного дизайну

Основні прийоми реалізації гнучкого та адаптивного дизайну: / налаштування області перегляду через метатег viewport; / використання відносних одиниць вимірювання — rem, em, відсотків, vw і fr замість фіксованих пікселів; / гнучкі модульні сітки на базі CSS Grid та Flexbox; / адаптивні зображення через max-width: 100%, srcset, sizes і <picture>; / та застосування медіазапитів @media із брейкпоінтами під різні пристрої та можливості вводу.

🗣️ Диктувати в ухо — Питання 4.4: Способи досягнення кросбраузерності

Основні способи досягнення кросбраузерності: / використання валідного семантичного HTML5 та скидання базових відступів на зразок box-sizing: border-box чи Normalize.css; / перевірка підтримки функцій через таблиці сумісності caniuse.com та MDN; / додавання вендорних префіксів -webkit- і -moz- або автоматизація через Autoprefixer; / використання директив @supports для резервних правил; / та безпосереднє тестування інтерфейсу в різних браузерних рушіях — Chromium, WebKit і Gecko.

🗣️ Диктувати в ухо — Питання 4.5: Причина відмінностей між браузерами

Головна причина відмінностей між браузерами полягає в тому, / що вони працюють на різних програмних рушіях рендерингу та виконання JavaScript: / Chromium, Chrome, Edge та Opera використовують Blink і V8, / Firefox використовує Gecko і SpiderMonkey, / а Safari — WebKit і JavaScriptCore. / Кожен рушій має власні таблиці стилів за замовчуванням, по-різному реалізує окремі CSS-специфікації на кшталт 3D-трансформацій чи скролбарів, / а також із різною швидкістю впроваджує нові вебстандарти.

🗣️ Диктувати в ухо — Питання 4.6: Інструменти вимірювання метрик

Для вимірювання метрик ефективності в роботі використано Google Lighthouse, вбудований у Chrome DevTools — / він оцінює продуктивність, доступність, найкращі практики та SEO, а також показники Core Web Vitals: FCP, LCP, TBT та CLS. / Потенційно для таких замірів також можуть використовуватися сервіси PageSpeed Insights, WebPageTest, GTmetrix, вкладки Performance та Network у DevTools і бібліотека web-vitals для збору метрик від реальних користувачів.

На цьому захист лабораторної роботи номер п’ять завершено. / Дякую за увагу!
